🔗 GitHub Connection

The extension uses a Personal Access Token to create repos and push commits on your behalf. Your token is stored locally in Chrome — it never leaves your device.

—
Connected via Personal Access Token ✓

Need a token? Generate one on GitHub — select the repo scope, then paste it above.

🔒 Privacy & Data
  • Your token is stored in chrome.storage.local — only accessible by this extension.
  • Gradescope session cookies are never read directly; files are fetched using your active browser session.
  • Files travel directly from Gradescope to GitHub via the Git Data API — no external servers involved.
  • Repos are created as private by default.
ℹ About
Gradescope Archiver v0.2.0
  • Scrapes submitted files from Gradescope course pages.
  • Uploads each file as a blob via the GitHub Git Data API.
  • Built with Manifest V3 — no background server required.
