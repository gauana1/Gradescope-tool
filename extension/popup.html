Gradescope Archiver

Automatically back up your submissions to a private GitHub repo.

Welcome! 👋

This extension scrapes your Gradescope courses and uploads all submitted files to a private GitHub repository you own.

What you'll need:
  1. A GitHub account
  2. A Personal Access Token with repo scope
  3. Be logged in to Gradescope in this browser

Setup takes ~2 minutes. Your token is stored locally and never leaves your device.

Connect GitHub 🔗

Create a token:
  1. Go to github.com/settings/tokens/new
  2. Give it a name like gradescope-archiver
  3. Check the repo scope
  4. Click Generate token and copy it

All set! 🎉

GitHub connected ✓ — ready to archive

Next, visit your Gradescope dashboard so the extension can find your courses, then press Refresh.
